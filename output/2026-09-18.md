### 1. bleedline/aimoneyhunter
> 来源：GitHub | [原文链接](https://github.com/bleedline/aimoneyhunter)

## 项目名称
AI副业赚钱指南合集，通过GitHub开源文档教授利用AI工具开展副业项目的系统方法。

## 核心逻辑
该项目本身不直接赚钱，而是作为信息聚合与教程集合，向用户展示如何利用AI工具（如ChatGPT、Midjourney等）提供副业服务来赚取额外收入。其变现逻辑是：用户学习其中的AI副业方法后，自行对外提供服务或产品来收费。

## 启动成本
- 金钱成本：0元（GitHub内容免费获取）；若需使用AI工具，ChatGPT Plus约145元/月，Midjourney约70元/月，合计约215元/月。
- 时间成本：阅读学习约3-5小时；选定方向并完成首单准备约10-20小时。

## 执行步骤
1. 打开GitHub链接，通读README及分类目录，筛选出适合自己技能和资源的1-2个AI副业方向（如AI写作、AI绘画、AI简历优化等）。
2. 针对选定方向，注册并熟悉所需AI工具，产出3-5个样品/案例，用于对外展示。
3. 在闲鱼、小红书、Upwork等平台发布服务商品，定价接单，完成交付并收集反馈，迭代优化。

## 收入模式
- 收费方式：按单收费、按字数/张数收费、包月服务等。
- 客单价范围：AI写作50-500元/篇；AI绘画30-300元/张；AI简历优化50-200元/份。
- 预估月收入：新手500-3000元；熟练后3000-10000元不等，取决于接单量和单价。

## 单人可执行
是。仅需一台电脑、网络、AI工具账号及基础学习能力即可启动，无需团队或特殊资源。

## 第一周行动清单
1. 通读该GitHub仓库全部内容，列出3个最感兴趣的AI副业方向并排序。
2. 选定1个方向，注册所需AI工具，完成3个模拟作品/案例。
3. 在闲鱼或小红书发布1条服务商品链接，设定初始低价（如9.9元）测试市场需求。

## 风险点
- 项目本身不赚钱，只是信息集合，若只收藏不执行则零收益。
- AI工具使用门槛被低估，实际产出质量可能不达客户预期。
- 平台竞争激烈，同质化严重，新手难以获得首批客户。
- AI工具政策或价格变动可能导致成本上升或方法失效。
- 部分副业方向存在版权或平台合规风险（如AI生成内容商用限制）。

### 2. public-apis/public-apis
> 来源：GitHub | [原文链接](https://github.com/public-apis/public-apis)

## 项目名称
一个免费 API 聚合清单，基于 GitHub 开源维护，通过流量与生态衍生变现。

## 核心逻辑
项目本身是免费 API 的索引仓库，不直接收费；赚钱来自围绕该仓库形成的流量、品牌和开发者信任，再通过赞助、广告、招聘信息、付费推广位、周边服务或导流到自有产品变现。本质是“用开源清单获取精准开发者流量，再把流量二次变现”。

## 启动成本
金钱成本：0-500 美元，主要是域名、托管、基础工具和初期推广费用。  
时间成本：初期整理与维护约 20-40 小时，之后每周 5-10 小时持续维护。

## 执行步骤
1. 复制或 fork 该仓库结构，建立自己的免费 API/工具导航站或垂直清单，明确一个细分方向。
2. 通过 GitHub、Reddit、Hacker News、开发者社区和 SEO 内容持续引流，积累邮件订阅或社群。
3. 当流量稳定后，接入赞助位、联盟推广、招聘板块、付费提交或导流到自有 SaaS/工具进行变现。

## 收入模式
收入方式包括：赞助商广告、付费置顶提交、联盟佣金、招聘信息发布、 newsletter 广告、导流到付费产品。  
客单价范围：50-2000 美元/月/赞助位，付费提交 20-200 美元/次。  
预估月收入：早期 0-500 美元；稳定后 500-5000 美元；头部开发者导航站可达 1 万+ 美元。

## 单人可执行
是。单人可执行，但需要持续内容维护、社区运营和基础 SEO/推广能力。

## 第一周行动清单
1. 选定一个细分方向，例如“AI 免费 API”“独立开发者免费工具”“跨境电商 API”，列出 50-100 个条目。
2. 搭建一个极简网站或 GitHub 仓库，包含分类、搜索、提交入口和邮件订阅。
3. 在 3 个开发者社区发布清单，收集反馈并开始积累第一批用户和订阅者。

## 风险点
1. 原项目已非常知名，直接复制很难竞争，容易被视为低质量搬运。
2. 免费 API 链接失效快，维护成本高，用户体验容易下降。
3. 流量增长慢，变现周期长，早期容易放弃。
4. 赞助和广告收入依赖规模，若无法形成精准流量，商业价值有限。
5. GitHub 仓库本身不直接赚钱，若没有站外产品和变现设计，可能只有 star 没有收入。
